## Requirements
### Requirement: 음식별 분석 출력
시스템은 사진을 분석해 **음식별 항목 배열**(각 항목: 이름, 칼로리, 탄수화물, 단백질, 지방, 사진 내 위치 박스)과 전체 신뢰도·비고를 반환해야 한다(SHALL). 위치 박스는 이미지 정규화 좌표(0~1)여야 하며, 오버레이 렌더링 전용으로 저장하지 않아야 한다(MUST NOT). 음식이 없으면 항목 배열은 비어 있어야 한다(MUST).

#### Scenario: 여러 음식 분석
- **WHEN** 여러 음식이 담긴 사진을 분석하면
- **THEN** 각 음식이 이름·영양값·위치 박스를 가진 항목으로 반환되고, 저장은 이 시점에 이루어지지 않는다

#### Scenario: 음식 미검출
- **WHEN** 음식이 식별되지 않으면
- **THEN** 빈 항목 배열과 안내 비고를 반환한다

### Requirement: 사진 위 오버레이와 목록형 폴백
프론트엔드는 촬영/선택한 사진을 확인 화면에 표시하고, 각 음식 위치에 박스와 라벨(이름·영양값)을 그려야 한다(SHALL). 모든 항목에 유효한 박스가 있고 전체 신뢰도가 임계 이상일 때만 오버레이를 사용하고, 그렇지 않으면 목록형(사진 아래 음식 카드 목록)으로 자동 전환해야 한다(MUST). 오버레이를 쓰는 경우에도 분석 요약(음식 수·총 칼로리·탄단지)과 음식별 목록을 함께 표시해 값을 훑고 수정할 수 있어야 한다(MUST). 사진은 저장하지 않고 촬영 세션에서만 사용해야 한다(MUST NOT persist).

#### Scenario: 오버레이 표시
- **WHEN** 항목들이 유효한 박스와 충분한 신뢰도를 가지면
- **THEN** 사진 위에 각 음식 박스와 이름·영양값 라벨이 표시된다

#### Scenario: 목록형 폴백
- **WHEN** 박스가 없거나 신뢰도가 임계 미만이면
- **THEN** 사진 아래에 음식별 카드 목록으로 표시된다

#### Scenario: 요약과 목록 동시 표시
- **WHEN** 오버레이 모드로 분석 결과를 확인하면
- **THEN** 음식 수·총 칼로리·탄단지 요약과 음식별 목록이 사진과 함께 표시되고, 목록에서 항목을 눌러 수정할 수 있다

### Requirement: 음식별 수정과 합계 자동 재계산
사용자는 각 음식의 이름·영양값을 수정하고, 항목을 추가·삭제할 수 있어야 한다(SHALL). 합계(총 칼로리·탄단지)는 항목 합으로 자동 재계산되어 표시되어야 한다(MUST).

#### Scenario: 항목 수정 시 합계 갱신
- **WHEN** 사용자가 한 음식의 칼로리를 바꾸면
- **THEN** 하단 합계가 즉시 재계산되어 반영된다

#### Scenario: 항목 추가·삭제
- **WHEN** 사용자가 음식을 추가하거나 삭제하면
- **THEN** 목록과 합계가 함께 갱신된다
