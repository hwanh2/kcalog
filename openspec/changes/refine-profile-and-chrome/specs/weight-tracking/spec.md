# weight-tracking 변경

## ADDED Requirements

### Requirement: 추세 표시 범위 라벨

체중 추세선의 표시 범위를 고르는 라벨은 **기간으로 읽혀야 하며, 특정 달을 가리키는 것으로 읽혀서는 안 된다**(MUST NOT). `1월`·`3월`은 "1개월"의 줄임으로 쓰였지만 한국어에서 그 표기는 January·March다 — 회원이 실제로 "3월이 왜 나오냐"고 물었다.

#### Scenario: 범위 라벨
- **WHEN** 회원이 체중 추세선의 범위 토글을 보면
- **THEN** `1주` · `1개월` · `3개월`로 표시되고, 고른 범위만큼의 기록이 그려진다

### Requirement: 추세선은 도판 전체를 쓴다

추세선은 그릴 점들을 **도판의 가로 폭 전체에 고르게 늘어놓아야 한다**(MUST). 특히 **가장 최근 기록은 오른쪽 끝에 와야 한다**(MUST) — 오른쪽이 비어 있으면 방금 저장한 오늘 값이 그래프에 들어가지 않은 것으로 읽힌다.

x축 라벨은 **자기 점이 찍힌 가로 위치에 놓여야 한다**(MUST). 라벨만 도판 양끝까지 벌리면 점과 어긋나 잘못된 날짜로 읽힌다.

#### Scenario: 오늘 체중을 저장한 직후
- **WHEN** 회원이 오늘 체중을 저장하고 추세선을 보면
- **THEN** 오늘 점이 그래프 오른쪽 끝에 찍히고, 그 아래 `오늘` 라벨과 같은 위치에 있다

#### Scenario: 축 라벨
- **WHEN** 회원이 추세선의 x축 라벨을 보면
- **THEN** 각 라벨이 자기 점 바로 아래에 있고, 도판 밖으로 넘치지 않는다

### Requirement: 오늘 기록 여부를 알린다

체중 입력 카드는 **그날 기록이 이미 있는지를 보여줘야 한다**(MUST). 그날 기록이 없을 때 채워 넣은 최근값은 이미 출처를 밝히고 있지만, **기록이 있을 때는 아무 표시가 없어** 저장이 됐는지 알 수 없었다 — 저장에 성공해도 화면이 그대로다.

#### Scenario: 오늘 기록이 있을 때
- **WHEN** 회원이 오늘 체중을 이미 기록한 상태로 체중 탭을 열면
- **THEN** 입력 카드에 오늘 기록됐음이 표시된다

#### Scenario: 저장 직후
- **WHEN** 회원이 오늘 체중을 저장하면
- **THEN** 같은 표시가 켜져 저장된 것을 알 수 있다

#### Scenario: 오늘 기록이 없을 때
- **WHEN** 회원이 오늘 체중을 아직 기록하지 않았으면
- **THEN** 그 표시는 없다
