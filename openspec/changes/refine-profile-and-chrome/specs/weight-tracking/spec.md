# weight-tracking 변경

## ADDED Requirements

### Requirement: 추세 표시 범위 라벨

체중 추세선의 표시 범위를 고르는 라벨은 **기간으로 읽혀야 하며, 특정 달을 가리키는 것으로 읽혀서는 안 된다**(MUST NOT). `1월`·`3월`은 "1개월"의 줄임으로 쓰였지만 한국어에서 그 표기는 January·March다 — 회원이 실제로 "3월이 왜 나오냐"고 물었다.

#### Scenario: 범위 라벨
- **WHEN** 회원이 체중 추세선의 범위 토글을 보면
- **THEN** `1주` · `1개월` · `3개월`로 표시되고, 고른 범위만큼의 기록이 그려진다
