# ui-feedback 변경

## ADDED Requirements

### Requirement: 빈 상태는 한 가지 모양으로

목록이 비었을 때의 안내는 **앱 전체에서 같은 모양이어야 한다**(MUST) — 그림 + 무엇을 하면 채워지는지. 화면마다 "비어 있음"이 다른 모양이면 그 차이 자체가 정보처럼 읽혀 잡음이 된다.

한 줄짜리 문구를 **큰 라운드 카드에 담아서는 안 된다**(MUST NOT) — 내용에 비해 면이 커서 알약처럼 떠 보이고, 정작 전할 사실은 작게 읽힌다.

빈 상태의 그림은 **보일 만큼 진해야 한다**(MUST). 면과 거의 같은 밝기면 자리만 차지하고 아무것도 전하지 않는다.

⚠️ 바로 아래에 같은 곳으로 가는 진입점이 이미 있으면 **빈 상태에 행동 버튼을 또 두지 않는다**(SHOULD NOT).

#### Scenario: 끼니에 기록이 없을 때
- **WHEN** 회원이 아직 아무것도 담지 않은 끼니를 보면
- **THEN** 즐겨찾기 빈 상태와 같은 모양(그림 + 문구)으로 안내가 뜬다

### Requirement: 파괴적 확인 버튼

되돌릴 수 없는 동작의 확인 버튼은 **버튼으로 읽혀야 한다**(MUST). 색 없는 글씨만으로는 무엇을 눌러야 실행되는지 찾게 된다.

동시에 **기본 선택은 취소여야 한다**(MUST). 실행을 눈에 띄게 하되, 취소를 **넓게·앞에** 두어 습관적으로 누르는 손가락이 취소에 먼저 닿게 한다 — 눈에 띄는 것과 손이 먼저 가는 것은 다르다.

#### Scenario: 세트 삭제 확인
- **WHEN** 회원이 세트 삭제 확인 시트를 보면
- **THEN** 실행 버튼이 색이 채워진 버튼으로 보이고, 취소가 더 넓게 앞에 있다
