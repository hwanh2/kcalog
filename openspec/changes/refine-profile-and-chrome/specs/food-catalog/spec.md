# food-catalog 변경

## MODIFIED Requirements

### Requirement: 음식 검색

시스템은 이름으로 음식을 찾을 수 있게 해야 한다(SHALL). 검색은 카탈로그와 회원의 즐겨찾기를 함께 대상으로 해야 하며(MUST), 결과에는 각 항목의 출처(카탈로그/즐겨찾기)가 구분되어야 한다(MUST). 매칭은 공백·대소문자 차이를 흡수해야 하고(MUST), 항목에 등록된 별칭으로도 찾을 수 있어야 한다(MUST).

**검색 입력은 목록이 길어 찾기가 필요한 자리에만 두어야 한다**(MUST). 회원이 직접 저장한 즐겨찾기 목록에는 두지 않는다 — 스스로 담은 몇 개가 이미 화면에 다 보이는데, 검색창이 목록보다 먼저 오면 자리만 차지한다.

#### Scenario: 이름 검색
- **WHEN** 회원이 "닭 가슴살"로 검색하면
- **THEN** 공백을 무시하고 "닭가슴살"이 결과에 나온다

#### Scenario: 별칭 검색
- **WHEN** 회원이 "계란"으로 검색하고 "삶은달걀"에 그 별칭이 등록되어 있으면
- **THEN** "삶은달걀"이 결과에 나온다

#### Scenario: 즐겨찾기 목록
- **WHEN** 회원이 즐겨찾기 탭을 열면
- **THEN** 검색 입력 없이 저장한 세트와 음식이 바로 보인다
