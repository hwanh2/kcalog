# daily-dashboard 변경

## ADDED Requirements

### Requirement: 홈 식사 줄의 자리표시와 끼니 표식

홈의 오늘 기록 목록에서 **사진이 없는 기록도 사진이 있는 기록과 같은 자리를 차지해야 한다**(MUST). 빈 칸으로 두면 줄마다 글자 시작점이 달라져 목록이 흐트러진다. 자리표시 아이콘은 **다른 화면의 같은 자리와 같아야 한다**(MUST).

홈은 여러 끼니가 **한 목록에 섞이는 자리**이므로, 각 줄이 어느 끼니인지 훑어서 구분되어야 한다(MUST).

목록은 **끼니 순서(아침→점심→저녁→간식→야식)로, 같은 끼니 안에서는 시각순으로** 정렬해야 한다(MUST). 저장 시각만으로 정렬하면 **뒤늦게 채워 넣은 아침이 저녁 아래로 간다** — 하루를 훑는 목록에서 무엇을 빠뜨렸는지 알 수 없게 된다.

⚠️ 끼니를 **색으로 구분해서는 안 된다**(MUST NOT) — 같은 줄에 탄단지 칩이 이미 색을 쓰고 있어, 끼니에 색을 배정하면 그 칩들과 섞여 읽힌다.

#### Scenario: 사진 없는 기록
- **WHEN** 회원이 사진 없이 담은 기록(카탈로그·즐겨찾기·직접 입력)을 홈에서 보면
- **THEN** 빈 칸 대신 자리표시가 들어가 사진 있는 줄과 같은 자리에서 글자가 시작한다

#### Scenario: 여러 끼니가 섞인 목록
- **WHEN** 회원이 하루에 아침·점심·저녁을 기록하고 홈을 보면
- **THEN** 각 줄이 어느 끼니인지 색이 아닌 표식으로 구분된다

#### Scenario: 뒤늦게 채운 아침
- **WHEN** 회원이 저녁을 먼저 기록하고 나중에 그날 아침을 채워 넣으면
- **THEN** 홈 목록에서 아침이 저녁보다 위에 온다
