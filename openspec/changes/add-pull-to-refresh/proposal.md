# 당겨서 새로고침

## 왜

홈 화면에서 띄운 앱(standalone)에는 **다시 불러올 방법이 없다.**

주소창이 없으니 새로고침 버튼이 없고, 브라우저가 주는 당겨서 새로고침도 standalone에서는 동작하지 않는다. 지금 화면을 갱신하려면 **다른 탭으로 갔다가 돌아와야 한다** — 그것도 우연히 그렇게 되는 것이지 회원이 알고 쓰는 수단이 아니다.

코드에도 갱신 경로가 없다. `refetch`를 부르는 자리가 한 곳도 없고, 데이터는 화면이 마운트될 때와 저장 뒤 무효화될 때만 다시 온다. 다른 기기에서 기록했거나, 네트워크가 잠깐 끊겼다 돌아온 경우에 화면이 낡은 채로 남는다.

## 무엇을

문서 맨 위에서 아래로 당기면 **지금 화면이 쓰고 있는 조회를 전부 다시 부른다.**

- 셸(`AppShell`)에 한 번만 둔다 — 화면마다 붙이면 새로 만드는 탭에서 빠뜨린다
- 임계점을 넘겨야 돈다. 못 미치면 아무 일도 없이 되돌아간다
- 당긴 만큼 따라 내려오는 표시로 얼마나 더 가야 하는지 알린다
- 시트 안에서, 자기 스크롤이 내려간 영역에서, 문서가 맨 위가 아닐 때는 **시작하지 않는다**

## 영향

- 스펙: `app-shell` (새로고침 수단 추가)
- 코드: `lib/usePullToRefresh`(신규) · `ui/PullIndicator`(신규) · `shell/AppShell` · `test/utils`(셸이 QueryClient를 쓰게 되어 공통 렌더에 provider 추가)
- 의존성 변화 없음

⚠️ **터치 전용이다.** 마우스·키보드로는 새로고침할 수 없다 — 데스크톱 브라우저에는 주소창 새로고침이 있어 이 수단이 필요 없고, 없는 문제를 위해 두 벌을 만들지 않는다.
