# app-shell 변경

## ADDED Requirements

### Requirement: 당겨서 다시 불러온다

회원은 **화면을 아래로 당겨 지금 보고 있는 내용을 다시 불러올 수 있어야 한다**(SHALL). 홈 화면에서 띄운 앱에는 주소창도, 브라우저가 주는 당겨서 새로고침도 없어 갱신 수단이 아예 없다.

다시 부르는 대상은 **그 화면이 실제로 쓰고 있는 조회 전부**여야 한다(MUST) — 화면마다 무엇을 다시 부를지 따로 적으면 새 화면에서 빠뜨린다.

#### Scenario: 맨 위에서 당기기
- **WHEN** 회원이 화면 맨 위에서 아래로 충분히 당겼다 놓으면
- **THEN** 그 화면의 내용을 다시 불러오고, 도는 동안 그 사실이 보인다

#### Scenario: 조금만 당기기
- **WHEN** 회원이 당겼다가 되는 지점에 못 미친 채 놓으면
- **THEN** 아무 일도 일어나지 않고 표시가 걷힌다

### Requirement: 당기는 동안 얼마나 남았는지 보인다

당기는 동안 **얼마나 더 가야 하는지가 보여야 한다**(MUST). 되는 지점을 모르면 회원은 짐작으로 당기고, 안 되면 될 때까지 되풀이한다.

표시는 **본문의 자리를 차지해서는 안 된다**(MUST NOT) — 당길 때마다 내용이 통째로 밀려 내려가면 무엇이 새로고침되는지 보이지 않는다.

#### Scenario: 당기는 중
- **WHEN** 회원이 화면을 아래로 당기고 있으면
- **THEN** 당긴 만큼 따라오는 표시가 보이고, 되는 지점을 넘기면 그 사실이 드러난다

### Requirement: 스크롤·시트와 다투지 않는다

당겨서 새로고침은 **평범한 스크롤을 가로채서는 안 된다**(MUST NOT). 다음 경우에는 시작하지 않아야 한다(MUST).

- 문서가 맨 위가 아닐 때 — 목록 중간에서 당기는 것은 스크롤이다
- 시트가 떠 있고 그 안에서 당길 때 — 시트는 화면 위에 떠 있어 뒤 문서는 맨 위지만, 뒤 화면을 새로고침할 이유는 없다
- 자기 스크롤을 가진 영역이 내려가 있을 때 — 그쪽 스크롤이 먼저다

#### Scenario: 목록 중간에서 당기기
- **WHEN** 회원이 화면을 내려본 상태에서 아래로 당기면
- **THEN** 평범하게 스크롤되고 새로고침되지 않는다

#### Scenario: 시트 안에서 당기기
- **WHEN** 회원이 열려 있는 시트 안에서 아래로 당기면
- **THEN** 뒤 화면이 새로고침되지 않는다

### Requirement: 새로고침은 겹치지 않고, 실패해도 걷힌다

새로고침이 도는 동안 다시 당겨도 **겹쳐 부르지 않아야 한다**(MUST NOT). 다시 부르기가 **실패하더라도 표시는 걷혀야 한다**(MUST) — 남아 있으면 화면이 잠긴 것처럼 보인다.

#### Scenario: 도는 동안 다시 당기기
- **WHEN** 회원이 새로고침이 도는 동안 다시 당겼다 놓으면
- **THEN** 새 요청이 시작되지 않는다

#### Scenario: 다시 부르기 실패
- **WHEN** 연결이 끊겨 다시 부르기가 실패하면
- **THEN** 표시가 걷히고, 실패는 각 화면이 자기 자리에서 알린다
