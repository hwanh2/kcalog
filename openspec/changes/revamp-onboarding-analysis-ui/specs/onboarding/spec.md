# onboarding (delta)

## ADDED Requirements

### Requirement: 단계별 온보딩 진행
프론트엔드는 온보딩을 단계별로 진행해야 한다(SHALL). 각 단계는 하나의 질문만 묻고, 현재 위치를 알 수 있는 진행 표시와 다음 단계로 넘어가는 확정 버튼을 제공해야 한다(MUST). 필수 선택이 비어 있으면 다음으로 넘어갈 수 없어야 하며(MUST NOT), 이전 단계로 돌아가 수정할 수 있어야 한다(MUST). 마지막 단계에서 계산 결과를 확인한 뒤 제출해야 한다(MUST).

#### Scenario: 단계 이동
- **WHEN** 회원이 한 단계의 값을 고르고 다음을 누르면
- **THEN** 다음 단계로 이동하고 진행 표시가 갱신된다

#### Scenario: 미선택 시 진행 차단
- **WHEN** 필수 선택이 비어 있는 상태에서 다음을 누르려 하면
- **THEN** 다음 단계로 넘어가지 않는다

#### Scenario: 이전 단계 수정
- **WHEN** 회원이 뒤로 가서 앞 단계의 값을 바꾸면
- **THEN** 바뀐 값이 이후 계산에 반영된다

## MODIFIED Requirements

### Requirement: 프로필·목표 입력
시스템은 온보딩에서 성별, 출생연도, 키(cm), 현재 체중(kg), 활동량(LOW/MID/HIGH/VERY_HIGH), 목표 방향(감량/유지/증량)을 입력받아 검증 후 저장해야 한다(SHALL). 목표 체중(kg)은 선택 항목이어야 하며, 감량·증량을 선택한 경우에만 입력받고 비어 있어도 온보딩을 완료할 수 있어야 한다(MUST). 저장 시 현재 체중은 오늘 날짜의 `weight_log`로 기록해야 한다(MUST).

#### Scenario: 정상 제출
- **WHEN** 회원이 모든 항목을 유효하게 입력하고 제출하면
- **THEN** member 프로필 필드가 저장되고, 오늘 날짜 weight_log가 생성되며, 확정된 일일 칼로리 목표가 저장되어 온보딩이 완료된다

#### Scenario: 유효 범위 밖 입력
- **WHEN** 키/체중/출생연도가 허용 범위(예: 키 100~230cm, 체중 30~250kg, 출생연도 1920~현재)를 벗어나면
- **THEN** 400과 항목별 오류 메시지를 반환하고 아무것도 저장하지 않는다

#### Scenario: 목표 체중 없이 완료
- **WHEN** 회원이 목표 체중을 비운 채 제출하면
- **THEN** 목표 체중 없이 프로필과 목표 방향·일일 칼로리 목표가 저장되어 온보딩이 완료된다

### Requirement: 일일 칼로리 목표 자동 계산
시스템은 Mifflin-St Jeor BMR × 활동계수(LOW 1.2 / MID 1.5 / HIGH 1.75 / VERY_HIGH 1.9)로 유지칼로리를 구하고, 목표 방향 조정(감량 −500, 증량 +300, 유지 0)을 적용해 일일 칼로리 목표를 계산해야 한다(SHALL). 결과는 10kcal 단위로 반올림하고, 남 1500 / 여 1200 kcal 미만으로 내려가지 않아야 한다(MUST). 계산값은 제안값이며 사용자가 수정한 값을 최종 저장해야 한다(SHALL). 제안 응답은 유지칼로리와 탄단지 목표(g)를 함께 포함해 계산 근거를 보여줄 수 있어야 한다(MUST).

#### Scenario: 감량 목표 계산
- **WHEN** 목표 방향으로 감량을 선택하면
- **THEN** 유지칼로리 − 500을 10 단위 반올림한 값이 제안된다

#### Scenario: 하한선 클램프
- **WHEN** 계산 결과가 성별 하한선(남 1500 / 여 1200) 미만이면
- **THEN** 하한선 값으로 제안된다

#### Scenario: 사용자 수정
- **WHEN** 회원이 제안된 목표를 다른 값으로 수정해 제출하면
- **THEN** 수정한 값이 `daily_kcal_target`으로 저장된다

#### Scenario: 목표 체중 없이 계산
- **WHEN** 목표 체중을 비운 채 방향만 선택하면
- **THEN** 목표 체중 없이도 방향에 따른 제안 목표가 반환된다

#### Scenario: 계산 근거 제공
- **WHEN** 회원이 제안 칼로리를 조회하면
- **THEN** 유지칼로리와 제안 목표, 탄단지 목표(g)가 함께 반환된다
