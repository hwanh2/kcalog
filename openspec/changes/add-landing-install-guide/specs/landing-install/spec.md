# landing-install (delta)

## ADDED Requirements

### Requirement: 비회원 진입 화면
시스템은 서비스 기본 주소로 들어온 방문자에게 로그인을 요구하기 전에 서비스 소개와 설치 안내를 제공해야 한다(SHALL). 소개에는 서비스가 무엇을 해주는지와 주요 기능이 포함되어야 하며(MUST), 실제 앱 화면을 보여주어야 한다(SHALL).

#### Scenario: 링크로 처음 들어온 방문자
- **WHEN** 방문자가 브라우저에서 서비스 기본 주소를 열면
- **THEN** 서비스 설명과 설치 안내가 있는 화면을 보게 되고, 로그인부터 요구받지 않는다

#### Scenario: 앱 화면 확인
- **WHEN** 방문자가 소개 화면을 보면
- **THEN** 데이터가 채워진 실제 앱 화면을 확인할 수 있다

### Requirement: 설치 여부에 따른 진입 분기
시스템은 홈 화면에 설치된 앱으로 실행할 때와 브라우저에서 주소로 접근할 때를 구분해 서로 다른 화면으로 진입시켜야 한다(MUST). 설치된 앱에서 실행하면 소개 화면을 거치지 않고 곧바로 앱으로 들어가야 한다(MUST).

#### Scenario: 홈 화면 아이콘으로 실행
- **WHEN** 회원이 홈 화면에 추가한 아이콘으로 앱을 실행하면
- **THEN** 소개 화면을 거치지 않고 앱 화면으로 진입한다

#### Scenario: 브라우저로 앱 주소 직접 접근
- **WHEN** 사용자가 브라우저에서 앱 주소로 직접 들어오면
- **THEN** 앱이 정상 동작한다 (설치하지 않았다는 이유로 차단되지 않는다)

### Requirement: 기기별 설치 안내
시스템은 방문자의 기기에서 **실제로 가능한 설치 방법만** 안내해야 한다(MUST). 브라우저가 설치 프롬프트를 제공하는 환경에서는 안내 문구 대신 설치를 실행하는 수단을 제공해야 한다(SHALL). 설치 프롬프트를 제공하지 않는 모바일 환경에서는 사용자가 직접 수행할 동작을 안내해야 한다(SHALL). 설치가 무의미한 데스크톱 환경에서는 모바일 기기로 이어갈 수단을 제공해야 한다(SHALL).

안내는 특정 브라우저 사용을 요구해서는 안 된다(MUST NOT) — 해당 기기에서 다른 브라우저로도 설치가 가능하기 때문이다.

#### Scenario: 설치 프롬프트를 지원하는 환경
- **WHEN** 방문자의 브라우저가 앱 설치 프롬프트를 제공하는 상태에서 설치를 선택하면
- **THEN** 브라우저의 설치 절차가 즉시 시작된다

#### Scenario: 설치 프롬프트가 없는 모바일 환경
- **WHEN** 설치 프롬프트를 제공하지 않는 모바일 기기에서 방문자가 설치를 선택하면
- **THEN** 공유 메뉴에서 홈 화면에 추가하는 방법이 단계별로 안내된다

#### Scenario: 데스크톱 방문자
- **WHEN** 데스크톱에서 방문자가 설치를 선택하면
- **THEN** 모바일 기기로 같은 안내에 접속할 수 있는 수단이 제공된다

#### Scenario: 태블릿 식별
- **WHEN** 데스크톱 운영체제로 식별되지만 터치 입력을 지원하는 태블릿에서 접속하면
- **THEN** 데스크톱이 아니라 모바일 설치 안내가 제공된다

### Requirement: 설치 완료 후 안내 비노출
시스템은 이미 설치된 상태로 실행 중인 사용자에게 설치 안내를 노출해서는 안 된다(MUST NOT). 설치 여부 판정은 단일 지점에서 이루어져야 하며(SHALL), 설치 관련 UI는 그 판정 결과만 사용해야 한다(MUST).

#### Scenario: 설치한 사용자
- **WHEN** 홈 화면에 추가한 앱으로 실행 중인 사용자가 어느 화면을 보든
- **THEN** 설치를 권하는 안내나 버튼이 표시되지 않는다

### Requirement: 링크 공유·검색 노출
시스템은 소개 화면이 검색 결과와 메신저 링크 미리보기에 서비스명·설명·대표 이미지로 표시되도록 메타데이터를 제공해야 한다(SHALL).

#### Scenario: 메신저로 링크 공유
- **WHEN** 사용자가 서비스 주소를 메신저에 붙여넣으면
- **THEN** 서비스명과 설명, 대표 이미지가 담긴 미리보기가 표시된다
