## ADDED Requirements

### Requirement: 5탭 네비게이션과 카메라 FAB
시스템은 인증·온보딩 완료 회원에게 하단 5요소 네비게이션 — 홈, 리포트, 중앙 카메라 FAB, 체중, AI PT — 을 제공해야 한다(SHALL). 탭 전환은 서버 왕복 없이 이루어져야 하며(MUST), 현재 탭이 시각적으로 구분되어야 한다(MUST). 중앙 카메라 FAB는 어느 탭에서든 식사 촬영·기록 흐름으로 진입해야 한다(MUST). 온보딩 미완료 회원에게는 셸을 노출하지 않아야 한다(MUST — 기존 가드 규칙 유지). 아직 구현되지 않은 탭(리포트·AI PT)은 준비 중 안내 화면을 표시해야 한다(SHALL).

#### Scenario: 탭 이동
- **WHEN** 온보딩을 마친 회원이 하단 탭을 누르면
- **THEN** 해당 화면(홈/리포트/체중/AI PT)으로 서버 요청 없이 전환되고 현재 탭이 강조된다

#### Scenario: 카메라 FAB 진입
- **WHEN** 회원이 어느 탭에서든 중앙 카메라 FAB를 누르면
- **THEN** 식사 촬영·기록 흐름이 시작되고, 저장 완료 시 홈으로 복귀한다

#### Scenario: 준비 중 탭
- **WHEN** 회원이 리포트 또는 AI PT 탭을 누르면
- **THEN** 준비 중 안내 화면이 표시된다 (해당 기능 change에서 구현 예정)

#### Scenario: 온보딩 미완료 회원
- **WHEN** 온보딩을 마치지 않은 회원이 진입하면
- **THEN** 셸 대신 온보딩 화면으로 강제 이동된다

### Requirement: 프로필 진입 경로
시스템은 홈 헤더의 아이콘을 통해 프로필 화면으로 진입할 수 있게 해야 한다(SHALL). 프로필 화면의 기존 기능(프로필 조회·수정, 로그아웃)은 유지되어야 한다(MUST).

#### Scenario: 프로필 진입
- **WHEN** 회원이 홈 헤더의 프로필 아이콘을 누르면
- **THEN** 프로필 화면으로 이동하고, 기존 조회·수정·로그아웃 기능을 사용할 수 있다

## MODIFIED Requirements

### Requirement: 스타일 시스템
시스템은 화면 디자인 템플릿(`docs/png/`) 기준의 디자인 토큰 — 크림 배경, 오렌지 primary, 매크로 색상(탄 오렌지·단 그린·지 옐로), 카드 라운드 — 을 적용한 스타일 시스템을 갖춰야 한다(SHALL). 모든 기존 화면(온보딩·프로필·촬영 흐름 포함)이 이 토큰을 일관되게 사용해야 한다(MUST).

#### Scenario: 일관된 스타일 적용
- **WHEN** 회원이 어느 화면을 보든
- **THEN** 템플릿 기준 공통 디자인 토큰(색·간격·타이포·라운드)이 일관되게 적용되어 있다

#### Scenario: 모바일 우선 레이아웃
- **WHEN** 회원이 모바일 화면 폭에서 앱을 사용하면
- **THEN** 5탭 셸과 콘텐츠가 모바일에 맞게 배치된다
