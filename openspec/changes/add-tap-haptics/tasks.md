# 태스크

## 1. 조사

- [x] 1.1 iOS 사파리 Vibration API 지원 확인 — caniuse 기준 **3.2~26.5 전 버전 미지원**
- [x] 1.2 iOS 편법(`<input type="checkbox" switch>`) 확인 — 17.4~26.4에서만, **26.5에서 Apple이 막음**
- [x] 1.3 그래서 진동만으로는 부족하다는 결론 — 어느 기기에서나 오는 응답을 함께 둔다 (D1)

## 2. 진동

- [x] 2.1 `lib/haptics`의 `tapHaptic()` — 부르는 쪽은 지원 여부를 확인하지 않는다 (D2)
- [x] 2.2 표준이 먹으면 거기서 끝 — 안드로이드에서 스위치를 만들지 않는다
- [x] 2.3 iOS 편법은 **label을 클릭**한다. 스위치를 직접 누르면 상태만 바뀌고 안 울린다 (D3)
- [x] 2.4 스위치는 하나만 두고 상태만 바꾼다 — 매번 만들었다 지우면 낭독기가 읽을 틈이 생긴다
- [x] 2.5 `aria-hidden` · `tabIndex=-1` · `pointer-events:none`으로 접근성 트리와 탭 순서에서 뺀다
- [x] 2.6 `switch`는 `setAttribute`로 — React가 모르는 속성을 거치지 않게 한다

## 3. 눌림

- [x] 3.1 하단 탭에 `.press` — 저장·기록하기가 이미 쓰는 것과 같다. 탭에만 빠져 있었다
- [x] 3.2 FAB·화면 안 버튼에는 진동을 붙이지 않는다 — 누르는 것마다 울리면 소음이 된다 (D5)
