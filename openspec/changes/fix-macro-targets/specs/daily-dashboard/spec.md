# daily-dashboard 명세

## MODIFIED Requirements

### Requirement: 목표 대비 잔여와 구성 비율
시스템은 회원의 일일 칼로리 목표 대비 잔여 칼로리와, 탄단지 구성 비율을 산출할 수 있는 탄단지 gram 합계를 제공해야 한다(SHALL). 목표를 초과하면 잔여는 음수로 표현해야 한다(MUST). 구성 비율(%) 자체는 gram 합계로부터 클라이언트가 파생한다 — 서버는 gram 합계만 authoritative로 반환한다(design D6).

시스템은 **탄단지 목표(g)** 를 함께 반환해야 한다(SHALL). 목표는 일일 칼로리 목표와 **회원의 최근 체중**, **근육량 목표 여부**에서 파생한다(design D1).

- 비율은 근육량이 목표면 탄 45 / 단 30 / 지 25, 아니면 탄 55 / 단 20 / 지 25 (kcal 기준)
- **단백질은 체중당 1.2~2.0g 범위를 벗어나서는 안 된다**(MUST NOT) — 비율만으로 정하면 칼로리가 큰 회원은 필요 이상으로 높아지고, 감량 회원은 근손실을 막는 선 아래로 떨어진다(design D2)
- 지방은 목표 칼로리의 25%로 하고, 단백질이 범위에 잘려 남거나 모자란 칼로리는 **탄수화물이 흡수해야 한다**(MUST) — 지방은 이미 하한 근처라 더 깎으면 안 된다(design D6)
- 체중을 알 수 없으면 범위 제한 없이 비율만 적용한다(design D7)
- 칼로리 목표가 없으면 세 값 모두 null

#### Scenario: 잔여 칼로리
- **WHEN** 대시보드를 조회하면
- **THEN** `daily_kcal_target − 총 섭취`를 잔여 칼로리로, 탄단지 gram 합계와 함께 반환한다

#### Scenario: 목표 초과
- **WHEN** 총 섭취가 목표를 초과하면
- **THEN** 잔여 칼로리를 음수로 반환한다

#### Scenario: 탄단지 목표 반환
- **WHEN** 칼로리 목표와 체중이 있는 회원이 대시보드를 조회하면
- **THEN** 근육량 목표 여부에 따른 비율로 환산하되, 단백질은 체중당 1.2~2.0g으로 잘린 목표 g가 반환된다

#### Scenario: 단백질이 상한에 걸림
- **WHEN** 비율로 구한 단백질이 체중×2.0g을 넘으면
- **THEN** 단백질은 체중×2.0g으로 잘리고, 남은 칼로리는 탄수화물 목표에 더해진다

#### Scenario: 단백질이 하한에 걸림
- **WHEN** 비율로 구한 단백질이 체중×1.2g에 못 미치면
- **THEN** 단백질은 체중×1.2g으로 올라가고, 모자란 칼로리는 탄수화물 목표에서 빠진다

#### Scenario: 체중을 알 수 없는 회원
- **WHEN** 체중 기록이 없는 회원이 대시보드를 조회하면
- **THEN** 단백질 범위 제한 없이 비율만 적용한 목표 g가 반환된다

#### Scenario: 목표 미설정 회원
- **WHEN** 칼로리 목표가 없는 회원이 대시보드를 조회하면
- **THEN** 탄단지 목표는 null로 반환된다
