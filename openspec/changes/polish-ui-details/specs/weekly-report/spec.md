# weekly-report 변경

## ADDED Requirements

### Requirement: 조회 중인 기간을 화면에 밝힌다

리포트 화면은 **지금 보고 있는 기간의 실제 날짜 범위를 표시해야 한다**(MUST). "주간"·"월간" 같은 기간 이름만으로는 **어느 주·어느 달인지 알 수 없다**.

범위는 서버가 돌려주는 값(`rangeStart`·`rangeEnd`)을 그대로 써야 하며(MUST), 화면이 따로 계산해서는 안 된다(MUST NOT) — 집계에 쓰인 기간과 표시된 기간이 어긋나면 안 된다.

#### Scenario: 주간 리포트의 기간
- **WHEN** 회원이 주간 리포트를 보면
- **THEN** "8월 3일 – 8월 9일"처럼 그 주의 실제 날짜 범위가 함께 보인다

#### Scenario: 기간을 바꾸면 범위도 따라간다
- **WHEN** 회원이 월간으로 바꾸면
- **THEN** 표시되는 날짜 범위도 그 달의 범위로 바뀐다
