# daily-dashboard 변경

## MODIFIED Requirements

### Requirement: 홈 화면 구성
홈 화면은 v2 디자인 시안(`docs/png/01-home-v2-*.png`) 기준으로 다음 요소를 표시해야 한다(SHALL): 헤더(프로필 진입), 날짜 이동 행, 오늘의 칼로리 카드(남은 칼로리 링 게이지 + 섭취/목표 병기 + 상태 배지, 목표 초과 시 초과 표시), 탄단지 달성도 카드(매크로별 섭취 g/목표 g·달성률·진행 바), 체중 추세 미니카드(최근 체중·변화량·스파크라인), 오늘 기록한 식사 목록(끼니 구분·시각·음식명·매크로 칩·칼로리, "전체보기"로 음식기록 탭 진입), 다음 끼니 촬영 유도 카드. 식사 목록은 조회 전용이며 수정·삭제는 음식기록 탭이 담당한다.

촬영 유도 카드는 **현재 시각 기준의 끼니**를 안내해야 하며(MUST), 그 카드로 진입한 화면이 고르는 끼니와 **일치해야 한다**(MUST) — 홈이 안내한 끼니와 도착한 화면의 끼니가 다르면 안 된다. 카드는 음식기록 탭의 촬영 흐름으로 진입해야 한다(MUST).

#### Scenario: 홈 표시
- **WHEN** 온보딩을 마친 회원이 홈에 진입하면
- **THEN** 링 게이지·매크로 달성도·체중 미니카드·오늘 식사 목록·촬영 유도 카드가 표시된다

#### Scenario: 목표 초과 표시
- **WHEN** 섭취가 목표를 초과하면
- **THEN** 링 게이지와 잔여 표기가 초과 상태(위험 색·초과량)로 표시된다

#### Scenario: 체중 기록 없음
- **WHEN** 최근 체중 기록이 없으면
- **THEN** 체중 미니카드는 기록 유도 안내를 표시한다

#### Scenario: 전체보기 진입
- **WHEN** 회원이 오늘 식사 목록의 "전체보기"를 누르면
- **THEN** 음식기록 탭으로 이동해 해당 날짜의 기록을 수정·삭제할 수 있다

#### Scenario: 촬영 유도 카드 진입
- **WHEN** 회원이 촬영 유도 카드를 누르면
- **THEN** 음식기록 탭의 촬영 흐름이 열리고, 카드가 안내했던 끼니가 그대로 선택돼 있다

#### Scenario: 저녁 시간대의 끼니 안내
- **WHEN** 회원이 아무것도 기록하지 않은 채 저녁 시간대에 홈을 열면
- **THEN** 촬영 유도 카드는 "아침"이 아니라 그 시각의 끼니를 안내한다
