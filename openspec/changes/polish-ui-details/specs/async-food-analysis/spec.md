# async-food-analysis 변경

## ADDED Requirements

### Requirement: 사진은 촬영과 사진첩 모두에서 가져온다

사진을 고르는 자리는 **이미 찍어둔 사진도 고를 수 있어야 한다**(MUST). 카메라만 열려 **사진첩에 갈 수 없게 해서는 안 된다**(MUST NOT) — 먹고 나서 나중에 기록하는 경우가 사진을 찍는 순간만큼 흔하다.

다만 카메라 진입점(우하단 FAB)으로 들어온 경우에는 **촬영이 곧바로 열려야 한다**(MUST). 촬영하려고 들어온 사람에게 선택지를 한 번 더 묻지 않는다.

#### Scenario: 사진 영역을 눌러 고르기
- **WHEN** 회원이 음식기록 탭에서 사진 영역을 누르면
- **THEN** 촬영과 사진첩 중에서 고를 수 있다

#### Scenario: 카메라 FAB으로 진입
- **WHEN** 회원이 우하단 카메라 버튼으로 들어오면
- **THEN** 촬영이 바로 열린다
