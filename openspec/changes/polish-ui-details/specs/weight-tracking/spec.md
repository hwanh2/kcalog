# weight-tracking 변경

## ADDED Requirements

### Requirement: 기록 없는 날의 입력 시작값

체중 입력 화면은 그날 기록이 없을 때 **가장 최근 기록값을 시작값으로 제시해야 한다**(MUST). 빈 칸이나 `0`에서 시작하게 해서는 안 된다(MUST NOT) — 체중은 어제와 오늘이 이어져 읽히는 숫자이고, 조절 버튼도 이미 최근값에서 출발한다.

⚠️ 제시된 값은 **그날 잰 값이 아니므로**, 화면은 그 값의 출처를 함께 알려야 한다(MUST). 그날 기록이 이미 있으면 그 값이 시작값이며, 이 안내를 표시하지 않아야 한다(MUST NOT).

기록이 하나도 없는 회원에게는 제시할 값이 없으므로 이 규칙이 적용되지 않는다.

#### Scenario: 다음 날 체중 입력
- **WHEN** 어제 체중을 기록한 회원이 오늘 체중 화면을 열면
- **THEN** 어제 값이 입력값으로 채워져 있고, 최근 기록값이라는 안내가 함께 보인다

#### Scenario: 그날 이미 기록한 경우
- **WHEN** 회원이 오늘 체중을 이미 기록한 뒤 화면을 다시 열면
- **THEN** 오늘 기록한 값이 채워져 있고, 최근 기록값 안내는 보이지 않는다

#### Scenario: 기록이 하나도 없는 회원
- **WHEN** 체중 기록이 한 번도 없는 회원이 화면을 열면
- **THEN** 입력칸은 비어 있고 안내도 보이지 않는다
