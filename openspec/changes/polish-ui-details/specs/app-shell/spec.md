# app-shell 변경

## ADDED Requirements

### Requirement: 화면 제목은 탭이 말한다

하단 탭이 이름으로 말하고 있는 화면은 **같은 이름을 본문에 다시 적지 않아야 한다**(MUST NOT). 반복된 제목은 첫 화면에서 실제 내용을 아래로 밀어낸다.

다만 각 화면은 **문서 구조상의 제목(`h1`)을 가져야 한다**(MUST) — 보이지 않게 두더라도 없애서는 안 된다. 스크린리더 사용자는 제목으로 화면을 식별하고 건너뛴다.

탭 이름으로 설명되지 않는 화면(프로필·온보딩처럼 탭에 없는 화면)은 보이는 제목을 유지해야 한다(SHALL).

#### Scenario: 탭에 있는 화면
- **WHEN** 회원이 체중·리포트·AI PT 탭으로 이동하면
- **THEN** 화면 맨 위에 탭 이름과 같은 제목이 다시 적혀 있지 않다

#### Scenario: 스크린리더의 화면 식별
- **WHEN** 스크린리더 사용자가 같은 화면에서 제목 목록을 훑으면
- **THEN** 그 화면의 이름이 제목으로 읽힌다
